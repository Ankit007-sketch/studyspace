# Studyspace

A local-first practice tracker for coding questions and learning tracks.

## Run it

Open `index.html` in Chrome or Edge. No install, account, or server is required. Your data saves automatically in that browser on this laptop.

Use **Export backup** in the sidebar to download your data as JSON. **Import backup** restores a previously exported file. Keep backups somewhere safe; clearing browser storage can erase the local copy.

## Included

- Collections such as LeetCode, Codeforces, and Striver Sheet
- Custom learning tracks with notes
- Question status, difficulty, topic, link, time spent, and personal notes
- Search and filters, collection progress, activity summary, and backup/restore
